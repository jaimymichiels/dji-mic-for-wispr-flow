The DJI wordmark shape comes from the logo served by [DJI's official website](https://www.dji.com/):

https://www-cdn.djiits.com/dps/176201ad61d0753e17d860c4ca117932.svg

`dji-logo.svg` uses an opaque black fill so Hammerspoon can render the shape as a
macOS template icon and use it as a mask for the inverted battery portion.
